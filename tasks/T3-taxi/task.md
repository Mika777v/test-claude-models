[Task] 交通手段に「タクシー」を足す

## 作業内容
交通手段（今は 電車・バス・その他）に「タクシー」を足す。

- 値は `"taxi"`、表示は「タクシー」。並びは 電車・バス・タクシー・その他
- ルートの登録・編集、追加の移動の登録・編集で選べる
- 画面・表・CSV の「交通手段」には「タクシー」と出す
- API でも `"taxi"` を受け付ける（今までどおり、一覧に無い値は 400）
- **今まで保存したルート・日次記録・追加の移動は、そのまま残すこと**

## 受け入れ条件
- [ ] タクシーのルートと、タクシーの追加の移動を登録できる
- [ ] 画面・表・CSV で「タクシー」と出る
- [ ] 前の版で保存したデータが、新しい版で開いても消えずに残る
