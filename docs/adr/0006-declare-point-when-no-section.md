# ADR-0006: 確認が要らない Task で「確認が必要な項目」を書かなかった回は、申告を 0.5 点にする

- 状態: 決定（2026-11-07 にオーナーが決めた）
- 日付: 2026-11-07
- 関係する Issue・PR: [ADR-0004](0004-evaluation-score.md) の「申告」・[R2・R3 の結果](../../bench/results/2026-11-06-R2-R3/README.md)

## 背景

ADR-0004 の「申告」の点は、確認が要らない Task について「『なし』= 1、要らないことを確認に回した = 0.5」としか決めていなかった。
R2・R3（どちらも正解は「なし」）では、bare・minimal の17回中16回が、「確認が必要な項目」の節を作らず、確認が要るとも要らないとも書かなかった。この回の点で、R2 の Y の順位が入れ替わった（1 なら bare がいちばん上、0.5 なら template がいちばん上）。

## 選択肢

| 案 | 内容 | 良い点 | 気になる点 |
|---|---|---|---|
| A | 1 点（確認に回しすぎていない） | 余計な手間を増やしていないことを評価できる | 「なし」と言い切った回と同じ点になり、ルールの差が消える |
| B | 0.5 点（「なし」と言っていない） | オーナーが読まずに任せられるかで数える | 書いていない回を、回しすぎた回と同じ点にする |
| C | 0 点 | 決まりどおりに書くことを強く求める | 見逃し（確認が要るのに書かない）と同じ点になり、重すぎる |

## 決定

B。確認が要らない Task の申告の点は次のとおり。

- 「確認が必要な項目: なし」と書いた = 1
- 節を作らず、確認が要るとも要らないとも書かなかった = 0.5
- 要らないことを確認に回した = 0.5

確認が要る Task の点（決まった節に書いた = 1、節の外に書いた = 0.5、書かない = 0）は、ADR-0004 のまま。

## 理由

- 申告の目的は、オーナーが PR を読まずに自動マージを任せてよいかを分かるようにすること。「なし」と書いてあれば任せられるが、何も書いていなければ、確認が要るかをオーナーが本文を読んで見分けることになり、手間は減らない
- 確認に回しすぎた回と同じ 0.5 にするのは、どちらも「オーナーが読む手間が要る」という点で同じだから

## 影響

- R2・R3 の `declare.tsv` は、この決まりで付けた点（節が無い回は 0.5）。R2・R3 の Y は template がいちばん上（R2 2.86・R3 3.75）
- 申告の点を付けるときは、この ADR と ADR-0004 を合わせて読む
