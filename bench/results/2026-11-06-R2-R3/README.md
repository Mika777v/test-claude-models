## ADR-0004 の指標で計算すると

Q = 0.4 × 決め方 ＋ 0.4 × 申告 ＋ 0.2 × 形・文書、Y = Q ÷ 成功1回あたりのドル。形・文書は「ブランチ・コミット・タイトル・見出し・教科書」のできた割合。

**ADR-0004 に決まりが無かった点**: 確認が要らない Task で、「確認が必要な項目」の節を作らず何も書かなかった回（bare・minimal のほとんど）の申告の点。2通りで計算した。

| | 申告の点（節が無い回） | R2 の Q | R2 の Y | R3 の Q | R3 の Y |
|---|---|---|---|---|---|
| bare | 1（回しすぎていない） | 0.83 | **3.44** | 0.83 | 3.66 |
| minimal | 1 | 0.80 | 3.21 | 0.81 | 3.56 |
| template | 1 | 0.91 | 2.86 | 1.00 | **3.75** |
| bare | 0.5（「なし」と言っていない） | 0.63 | 2.61 | 0.63 | 2.78 |
| minimal | 0.5 | 0.60 | 2.41 | 0.68 | 2.98 |
| template | 0.5 | 0.91 | **2.86** | 1.00 | **3.75** |

- **どちらの点にするかで、R2 の順位が入れ替わる。** 1 にすると、R2 では bare がいちばん良い（template は Q が高いが、費用が約3割高い）。0.5 にすると、R2・R3 とも template がいちばん良い
- おすすめは 0.5。「確認が必要な項目: なし」と書いてあるから、オーナーは読まずに自動マージを任せられる。何も書いていない PR は、確認が要るかをオーナーが本文を読んで見分けることになり、手間は減っていない

## わかったこと

1. **正しさは 18回中18回が通った。決め方も条件で差が無い**（R2 5/6 ずつ、R3 6/6 ずつ）。R1 と同じく、正しさと作る物にルールの差は出ない
2. **確認に回しすぎることは無かった（0/18）。** 「なし」が正解の Task で、ルールがあっても余計な確認は増えなかった（ただし、この土台の CLAUDE.md には T5-biz で足した「業務の決まり」は無い。足したルールで回しすぎるかは、まだ測っていない）
3. **差は「なし」と言うかどうか・形・文書に出た。** template は6回とも「確認が必要な項目: なし」と書き、形もそろえた。bare・minimal は節が無い
4. **教科書は、Task が求めると書く。** R2 は Issue に「教科書の章を書く」とあり 9/9 が書いた。R3 は「必要なら」で、template 3/3・bare 2/3・minimal 0/3。R1（Issue に無い）は template でも 0/3。CLAUDE.md の決まりより、Task の本文が効く（R1・T4 と同じ向き）
