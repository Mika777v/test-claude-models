## わかったこと

1. **9回とも、ほぼ実際の PR と同じ物を作った。** 触ったファイルは9回とも実際と同じ8つで、Issue に無い決め方（2000文字・空や null の扱い）も 9回中8回が実際と同じだった。条件の間で、正しさにも作る物にも差が無い。揺れ（仮説2の「安定」）も、どの条件でもほとんど無かった

## 決めたこと（#11 の基準に当てはめて）

- 正しさはどの条件でも通り、差は申告の場所・形に出た → **ADR-0003 の作り方で Task を増やす**（R2・R3）
- 仮説3: 確認の申告は template 3/3・bare 3/3（本文の中）。T1 のように「ルールが無いと申告しない」にはならなかった。**ガードレールとして効いたのはルールより ADR（後から読む文書）**。これは T2（後の AI は残った文書を真似る）と同じ向き
- 仮説2: 3つの条件とも同じくらい安定していて、順位は付かない。この Task は ADR に作り方まで書いてあり、易しすぎた
