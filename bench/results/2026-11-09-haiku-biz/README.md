## わかったこと

1. **Haiku でも template-biz は効いた。** T5 で業務の決まりを確認に回したのは 3/3（Sonnet・template-biz と同じ）。Q も同じ 0.90
2. **Haiku は Sonnet の 3〜4倍のトークンを読むが、ドルでは 1/4〜1/2。** そのため Y_tok（主）では Sonnet が上、ドルの Y では Haiku が上。ADR-0007 のとおり、主の読みは Sonnet・template-biz（T5）／Sonnet・template（T4）
3. **T5 の Haiku はとても安い（1回 $0.06）。** 入力の多くがキャッシュの読み出し（1回 150万前後のうち 130〜150万）で、Haiku の単価が安いため
4. **差分の比（`diff_ratio`）は、T 系の Task では読めない。** T5 の正解の例（`reference.patch`）は8行だけの最小限の例で、比が 12〜17倍になった。T4 には正解の例が無い。差分の比は、実際の PR が正解の R 系の Task でだけ読む
