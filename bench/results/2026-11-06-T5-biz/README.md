## わかったこと

1. **確認に回すのは 0/3 → 3/3 になった。** 3回とも「確認が必要な項目」の1行目に「業務の決まりを足している（変える）」と書き、自動マージせずに待つとした。足した項目の言い回し（「業務の決まり（何ができて何ができないか）を…」）を、そのまま引いた回もある
2. **要件定義にも書くようになった（2/3）。** 前のルールありは 0/3。確認の項目が「ファイル」ではなく「中身」になったので、決まりを足したなら要件定義にも、とつながったと読める（1回目は「要件定義は変更していない。同名を禁止する決まりは要件に未記載なので、確認をお願いします」と、書かなかったことを申告した）
3. **作る物は変わらなかった。** 3回とも編集は「対象外」のまま。ただし、編集の抜け道は3回ともオーナーへの問いとして渡した。要件の段階（Opus）は「抜け道が残ると目的が守れない」と編集でも 409 を勧めたので、**決める質は要件の段階のほうが上、オーナーの目に届く率は同じ**
4. **費用はほぼ変わらない**（$0.22 → $0.26。要件の段階は $1.07）

Issue に書いた基準（2/3 以上・$0.3 以下ならテンプレートに入れる）に当てはまる。
