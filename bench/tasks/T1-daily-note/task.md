[Task] 日次記録にメモを付ける

## 作業内容
その日の記録に、自由なメモを付けられるようにする（例: 「健康診断で直帰」「客先の住所が変わった」）。

- API: `PUT /api/daily-records/{date}/note`、本文は `{ "note": "..." }`
  - その日の記録が無ければ 404
  - `note` は文字列。前後の空白を除いて 200 文字まで。空（空白だけを含む）を送るとメモを消す
  - 201 文字以上のとき・文字列でないときは 400（`fieldErrors` の `field` は `"note"`）
  - 返すのは、メモを付けた後のその日の記録（`DailyRecord`）
- `DailyRecord` に `note`（任意の文字列）を足す。メモが無い日は、プロパティごと付けない
- 月の取得（`GET /api/daily-records?month=YYYY-MM`）でもメモを返す
- 勤務区分の保存（`PUT /api/daily-records/{date}`）と、一括設定の登録（`POST /api/daily-records/bulk`）では、メモを消さずに残す
- 画面: カレンダーの日の編集パネルでメモを入力して保存できる。表の表示にもメモを出す
- CSV: 最後の列に「メモ」を足す。その日の行のすべてに、同じメモを入れる

## 受け入れ条件
- [ ] 上の API のとおりに、メモを付ける・直す・消すことができる
- [ ] 月の取得でメモが返り、勤務区分の保存・一括設定の登録の後もメモが残る
- [ ] 日の編集パネルと表でメモを扱える
- [ ] CSV の最後の列にメモが出る
